# Quantium_Forage_Data_Analytics--Chips-Category-Customer-Insights-Retail-Analytics
This project is part of Quantium’s retail analytics initiative, focused on understanding customer purchasing behaviour in the chips category. The insights generated will support the supermarket’s strategic planning for the next six months.
Project Scope
The analysis involves four key stages:
1. Data Cleaning & Preparation
- Examine transaction data for inconsistencies, missing values, outliers, and correct category identification.
- Validate numeric fields across all tables.
- Apply necessary corrections and save cleaned datasets.
- Review customer data for similar issues (nulls, anomalies).
- Merge transaction and customer datasets for analysis.
2. Exploratory Data Analysis
  - Define metrics: total sales, sales drivers, regional performance.
- Identify where the highest sales are coming from.
- Create charts, graphs, and visual summaries.
- Document notable trends and insights.
3. Customer Segmentation
- Segment customers based on purchasing behaviour.
- Evaluate packet size preferences and their impact on sales.
- Highlight key customer groups driving category performance.
4. Strategic Recommendations
- Recommend target customer segments.
- Provide insights into packet size relevance.
- Formulate conclusions to guide category strategy.
Deliverables
- Cleaned datasets (CSV format)
